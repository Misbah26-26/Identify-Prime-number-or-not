# PRIME NUMBER PROGRAM IN C

This C program checks whether a given number is a prime number or not.
A prime number is a number greater than 1 that has only two factors : 1 and itself.

EXAMPLE :
Input = 7
Output = 7 is a Prime number .

# Concepts used :
- if-else condition
- for loop
- basic number logic

# Language used
C programming
